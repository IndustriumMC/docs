## What is it?

The Vanilla Experience is the easiest way into Industrium. You open Minecraft, enter the server address, and play: same world, same quests, same players as in the [Immersive Experience](/immersive-experience).

The server pushes the base game as far as it can using purely server-side techniques, such as structures built from _display entities_ (scaling, interpolation), to deliver visuals well beyond what vanilla normally offers.

## Join the server

<Steps>
  <Step title="Open Minecraft Java Edition">
    Launch the game on a supported version.
  </Step>
  <Step title="Add the server">
    Go to **Multiplayer**, then **Add Server**.
  </Step>
  <Step title="Enter the address">
    ```text Server address
    mc.industrium.net
    ```
  </Step>
  <Step title="Play">
    Join the server and follow the in-game guidance.
  </Step>
</Steps>

## Vanilla or Immersive?

|  | Vanilla Experience | Immersive Experience |
| --- | --- | --- |
| Installation | None | Industrium launcher |
| Content and gameplay | Complete | Complete |
| Structure rendering | Display entities | Real 3D assets |
| Models, sounds, animations, menus | Minecraft's own | Fully custom |
| Price | Free | Free |

<Tip>
  Not sure? Start in vanilla to discover the server, then move to Immersive when you want to see Industrium as it was designed.
</Tip>
